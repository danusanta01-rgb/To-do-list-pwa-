# 📋 To-Do List Pro PWA (Hackathon 2026)

Aplikasi To-Do List berbasis **Progressive Web App (PWA)** yang ultra-lightweight, cepat, dan interaktif. Dibuat murni menggunakan Vanilla HTML, CSS, dan JavaScript untuk memberikan performa 60 FPS pada perangkat spesifikasi rendah maupun laptop lama.

---

## 🌟 Fitur Unggulan

1. ** Custom Voice Persona (Web Speech API):**
   - **Pria:** Suara bernada rendah, tegas, dan berwibawa.
   - **Wanita:** Suara bernada tinggi, lembut, dan ramah.
   - Membacakan nama tugas dan status penyelesaian secara otomatis.

2. ⏰ Multi-Tiered Alarm System:
   - Opsi pengingat waktu tugas: Pas Waktu, **15 Menit**, **30 Menit**, hingga **60 Menit** sebelum deadline.
   - Terintegrasi dengan Web Notification API & Pembacaan Suara Otomatis.

3. **📱 Progressive Web App (PWA) & Offline Mode:**
   - Dilengkapi `sw.js` (Service Worker) untuk akses 100% offline.
   - Tombol kustom "Install App" untuk dipasang langsung di Android, iOS, maupun Desktop.

4. **⚡ Performa Ultra-Lightweight (60 FPS):**
   - Tanpa library/framework eksternal berat (Murni HTML/CSS/JS).
   - Menggunakan System Fonts OS dan animasi CSS GPU-accelerated.

---

## 🛠️ Teknologi yang Digunakan (Tech Stack)

- **Frontend:** HTML5, CSS3 (Vanilla), JavaScript (ES6+)
- **APIs:** Web Speech API, Web Notification API
- **PWA Features:** Service Worker, Web App Manifest
- **Storage:** LocalStorage API

---

## 🚀 Cara Menjalankan

1. Download / Clone folder proyek ini.
2. Buka file `index.html` langsung melalui browser pilihanmu (Chrome/Edge/Safari/Firefox).
3. Untuk fitur PWA & Service Worker optimal, jalankan melalui Web Server (https://strong-hamster-0de4fe.netlify.app).
